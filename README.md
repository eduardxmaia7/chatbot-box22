#  Chatbot - Oficina Box22 ⚙️

## 📌 Sobre o projeto

Assistente virtual desenvolvido em linguagem C, simulando um sistema de atendimento automatizado para uma loja.

O objetivo é oferecer respostas rápidas às dúvidas frequentes dos clientes e disponibilizar o contato do atendimento humano quando necessário.

## ⚙️ Funcionalidades

- Consulta de horário de funcionamento;
- Informações sobre formas de pagamento;
- Consulta de prazos de entrega;
- Informações sobre trocas e devoluções;
- Direcionamento para atendimento humano;
- Validação de entradas inválidas;
- Resumo das interações ao encerrar o atendimento.

## 💻 Conceitos utilizados

Durante o desenvolvimento, foram trabalhados conceitos fundamentais de programação:

- Variáveis e tipos de dados;
- Estruturas condicionais (`switch`);
- Laços de repetição (`do while`);
- Funções;
- Entrada e saída de dados (`scanf` e `printf`);
- Validação e tratamento de entradas;
- Contadores e operações aritméticas.

## 🚀 Como executar

Para executar o projeto, é necessário possuir um compilador C, como o GCC.

**1. Clone o repositório:**

```bash
git clone https://github.com/SEU-USUARIO/chatbot-loja-central.git
```

**2. Acesse a pasta do projeto:**

```bash
cd chatbot-loja-central
```

**3. Compile o código:**

```bash
gcc chatbot.c -o chatbot
```

**4. Execute o programa:**

No Linux ou macOS:

```bash
./chatbot
```

No Windows:

```bash
chatbot.exe
```
